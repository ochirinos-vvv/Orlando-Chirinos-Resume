- `assets/Orlando-Chirinos-CV.docx` — CV original.

## Publicar con GitHub Pages

1. Crea un repositorio público en GitHub, por ejemplo `Orlando-Chirinos-Resume`.
2. Sube todos los archivos manteniendo la estructura.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`.
6. Guarda la configuración.

La URL quedará con el formato:

`https://TU_USUARIO.github.io/Orlando-Chirinos-Resume/`

GitHub Pages publica archivos estáticos como HTML, CSS y JavaScript directamente desde el repositorio.
